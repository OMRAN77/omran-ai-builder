# مرحّل المكالمات — وكيل الاتّصال (للمالك أوّلًا)

خدمة صغيرة مستقلّة على Railway تجعل وكيل المحادثة **يتّصل فعليًّا** بعيادة أو صالون أو مطعم نيابةً عنك ويحجز.
هي الجسر بين خطّ الهاتف (Twilio) وجلسة الصوت الحيّ: تأخذ صوت الطرف الآخر إلى الوكيل، وصوت الوكيل إلى الخطّ، بلا أيّ
تحويل للصوت، و**بلا تسجيل**. منفصلة عن جسر Claude Code (`cc-bridge/`) عمدًا: نشره أو إعادة تشغيله لا يقطع مكالمة.

مفاتيح الهاتف والصوت تعيش هنا فقط (Railway). Vercel لا يحمل إلّا عنوان المرحّل وسرّه المشترك؛ وإلى أن تُضبط المفاتيح
يردّ التطبيق `relay_not_configured` ولا يتّصل بأحد.

## كيف تمشي المكالمة

1. تؤكّد البطاقة في المحادثة → Vercel (`call-start`، للمالك وحده) يبني موجز المكالمة والجلسة كاملة (التعليمات، الأدوات،
   الصوت) ويرسلها إلى `POST /call` هنا **موقّعة**.
2. المرحّل يطلب الرقم عبر Twilio (حدّ المدّة، بلا تسجيل) بـTwiML فيه `<Connect><Stream>` إلى `/stream/<callId>` ورمز
   عشوائيّ لهذه المكالمة وحدها.
3. حين يردّ الطرف الآخر يفتح Twilio المقبس → المرحّل يتحقّق من الرمز → يفتح جلسة الصوت الحيّ ويرسل الجلسة كما بناها Vercel.
   المقبس لا يُربط بالمكالمة إلّا بعد رسالة `start` برمزها: مقبس غريب سبق Twilio ثمّ سكت أو انقطع لا يحجزها ولا يُنهيها.
4. إن سكت الطرف الآخر ٢٫٥ ثانية يبدأ الوكيل بجملة الإفصاح (مساعد آليّ من التطبيق، نيابةً عن فلان، لغرض كذا، المكالمة آليّة
   ولا تُسجَّل، هل تسمح بالمتابعة؟). إن تكلّم الطرف الآخر فوق الوكيل يُمسح صوت الوكيل فورًا ويسكت، وما بقي في الطريق من
   ردّه المقطوع يُسقط فلا يُسمع بعد المسح؛ والردّ التالي (يعيد الإفصاح كاملًا إن قُطع) يمرّ كما هو.
   إن مضت ٤٠ ثانية بعد الردّ بلا كلام من الطرف الآخر ولا صوت من الوكيل: يُطلب من الوكيل وداع قصير ثمّ يُغلق الخطّ، والنتيجة `no_answer`.
5. الوكيل يحفظ النتيجة (`report_outcome`) ثمّ يودّع ويطلب `end_call` → المرحّل ينتظر حتّى يُسمع الوداع كاملًا ثمّ يُغلق الخطّ.
6. Vercel يقرأ `GET /call/<callId>` كلّ ثانيتين: الحال، المدّة، سطور نصّيّة قصيرة، والنتيجة. **كلّ مكالمة منتهية لها نتيجة:**
   إن انتهت قبل `report_outcome` (أغلق الطرف الآخر، انتهى الوقت، انقطعت الخدمة) تُبنى من سبب النهاية بجملة عربيّة قصيرة —
   `no_answer` إن لم يردّ أحد (مشغول، لا ردّ، أُلغيت أو انتهت قبل الردّ، أو صمت بعده)، و`failed` غير ذلك.

## المسارات

| المسار | ماذا يفعل | الحماية |
|---|---|---|
| `GET /health` | `{ ok, calls, twilio, openai, publicUrl, signing }` — أعلام نعم/لا وعدد المكالمات الجارية، **لا سرّ** | عامّ |
| `POST /call` | `{ callId, to, maxSec, session }` → يطلب الرقم → `202 { callId, state:'queued' }` | توقيع Vercel |
| `GET /call/<callId>` | `{ state, durationSec, transcript, outcome, ended, endReason }` | توقيع Vercel |
| `POST /call/<callId>/cancel` | يُنهي المكالمة (Twilio `Status=completed`) → `{ ok:true }` | توقيع Vercel |
| `POST /twilio/status/<callId>` | ردود حال Twilio (رنين، ردّ، انتهاء، المدّة) | توقيع Twilio (`X-Twilio-Signature`) |
| مقبس `/stream/<callId>` | صوت المكالمة (Twilio Media Streams) | رمز المكالمة في رسالة `start` |

ردود `POST /call` الأخرى (لـVercel): `400 bad_request|bad_phone`، `401 unauthorized` (مع `why`: `missing|expired|signature|replay`)،
`403 outside_hours`، `409 exists|busy`، `502 twilio`، `503 not_configured` (مع أسماء المتغيّرات الناقصة فقط).
`state` واحدة من: `queued|ringing|in-progress|completed|busy|no-answer|failed|canceled`.

## المتغيّرات

**في Railway (هذه الخدمة):**

| المتغيّر | القيمة |
|---|---|
| `OPENAI_API_KEY` | مفتاح الصوت الحيّ (نفس مفتاح Vercel) |
| `TWILIO_ACCOUNT_SID` | من لوحة Twilio (يبدأ بـ`AC`) |
| `TWILIO_AUTH_TOKEN` | من لوحة Twilio — سرّ، لا يوضع في أيّ مكان آخر |
| `TWILIO_FROM` | الرقم الذي اشتريته بصيغة دوليّة، مثل `+1…` |
| `CALL_RELAY_SECRET` | سرّ عشوائيّ ≥ ٢٤ حرفًا (نفسه في Vercel) |
| `PUBLIC_URL` | عنوان الخدمة `https://…up.railway.app` (إن تُرك فارغًا يُؤخذ من `RAILWAY_PUBLIC_DOMAIN`) |
| `PORT` | `8080` (الافتراضيّ) |
| `CALL_MODEL` | اختياريّ — `gpt-realtime-2.1` افتراضيًّا إن لم يرسل Vercel نموذجًا |
| `CALL_VOICE` | اختياريّ — `cedar` افتراضيًّا إن لم يرسل Vercel صوتًا |
| `CALL_STATE_DIR` | اختياريّ — `/tmp/calls` (سجلّ المكالمة ٢٤ ساعة؛ لا قرص دائم مطلوب) |

**في Vercel:** `CALL_RELAY_URL` = عنوان الخدمة نفسه (بلا `/` في آخره)، و`CALL_RELAY_SECRET` = السرّ نفسه.

توليد السرّ في PowerShell:

```powershell
$b = New-Object byte[] 48; [Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($b); [Convert]::ToBase64String($b)
```

## الإعداد على Railway (مرّة واحدة)

1. في مشروع Railway نفسه: **New → GitHub Repo → `OMRAN77/omran-ai-builder`** — خدمة **جديدة** بجانب الجسر، من الفرع `main`.
2. **Settings → Source:** Root Directory = `call-relay`، وWatch Paths = `/call-relay/**` (فلا يُعاد نشره إلّا إذا تغيّر المرحّل).
   Railway يجد `Dockerfile` في المجلّد ويبني منه.
3. **Variables:** أضف متغيّرات الجدول أعلاه.
4. **Settings → Networking → Generate Domain** على المنفذ `8080` (السطر `listening on :8080` في سجلّ النشر يؤكّده). انسخ العنوان
   إلى `PUBLIC_URL` هنا وإلى `CALL_RELAY_URL` في Vercel.
5. اختياريّ: **Healthcheck Path** = `/health`.
6. لا تضف قرصًا (Volume): الحاوية تعمل بمستخدم غير جذر، والسجلّ في `/tmp/calls` يكفي ٢٤ ساعة.

**لا تدمج تغييرًا في `call-relay/**` أثناء مكالمة:** إعادة النشر تقطع المكالمات الجارية (تُختم `failed` بسبب `relay_restart`).
`/health` يقول كم مكالمة جارية (`calls`).

## التأكّد أنّه شغّال

```powershell
Invoke-RestMethod https://<عنوان-الخدمة>/health
```

المطلوب: `ok=True calls=0 twilio=True openai=True publicUrl=True signing=True`. أيّ `False` = متغيّر ناقص أو خاطئ، وسطر
الإقلاع في سجلّ Railway يذكر أسماء الناقص (`missing: …`) بلا قيمه.

## Twilio (مرّة واحدة)

1. **ترقية الحساب:** الحساب التجريبيّ لا يتّصل إلّا بأرقام موثّقة ويُسمع الطرف الآخر رسالة «حساب تجريبيّ». من اللوحة:
   **Upgrade account** وأكمل بيانات الدفع.
2. **شراء رقم صوتيّ واحد:** **Phone Numbers → Manage → Buy a number**، رقم فيه خاصيّة **Voice**. رقم أمريكيّ هو الأسهل
   (أرقام الإمارات عند Twilio تحتاج ملفّات تنظيميّة)؛ الطرف الآخر سيرى رقمًا دوليًّا. ضعه في `TWILIO_FROM` بصيغة `+1…`.
   لا حاجة لضبط Webhook للرقم: المكالمات صادرة فقط والتعليمات تُرسل مع كلّ مكالمة.
3. **Voice Geographic Permissions = الإمارات وحدها:** **Voice → Settings → Geo permissions**: فعّل **United Arab Emirates** فقط
   وأطفئ كلّ دولة أخرى (ومنها الولايات المتّحدة/كندا المفعّلة افتراضيًّا). هذا يمنع أيّ اتّصال بخارج الإمارات حتّى لو تسرّب المفتاح.
4. **رصيد مسبق الدفع:** **Billing → Add funds** بمبلغ صغير، وأطفئ الشحن التلقائيّ (Auto-recharge)، واختياريًّا تنبيه استهلاك.
5. **لا تسجيل:** المرحّل يرسل `Record=false` ولا يسجّل شيئًا؛ لا تفعّل أيّ تسجيل مكالمات أو تفريغ (Voice Intelligence) في الحساب.
6. **المفاتيح:** من صفحة الحساب الرئيسيّة انسخ **Account SID** و**Auth Token** إلى متغيّرات Railway فقط.

## الأمان والخصوصيّة

- الإمارات وحدها (`+971` ثمّ ٨–٩ أرقام)؛ الطوارئ والأرقام القصيرة وما يبدأ بـ600/800/900 مرفوضة هنا أيضًا، لا في Vercel فقط.
- المكالمات الحقيقيّة ٠٨:٠٠–٢٢:٠٠ بتوقيت دبي فقط (حارس ثانٍ بعد Vercel)، وحدّ المدّة يُرسل لـTwilio (`TimeLimit`)، مع إيقاف
  صارم عند الحدّ + ١٠ ثوانٍ وصمّام أمان للمكالمة كلّها.
- طلبات Vercel موقّعة (HMAC-SHA256) وتُرفض بعد ٦٠ ثانية أو إن أُعيد إرسالها؛ ردود Twilio موقّعة (HMAC-SHA1)؛ مقبس الصوت لا يُقبل
  إلّا برمز المكالمة العشوائيّ، ومقبس واحد لكلّ مكالمة.
- الطلب بلا توقيع أو بطابع خارج النافذة أو بحجم معلن فوق الحدّ (٣٢ ك.ب لـ`POST /call`، ١٦ ك.ب لردّ حال Twilio) يُرفض من رؤوسه
  قبل قراءة جسمه، وردّ حال بلا `X-Twilio-Signature` كذلك — العنوان عامّ فلا يُحجز جسم لطلب مجهول.
- طلب Twilio REST مهلته ٨ ثوانٍ (Vercel ينتظر المرحّل ١٥): لا تخرج مكالمة بعد أن يكون التطبيق قد استسلم.
- لا صوت يُخزَّن أبدًا. ما يُكتب على القرص (٢٤ ساعة ثمّ يُحذف): الحال، المدّة، النتيجة، وسطور نصّيّة قصيرة. الرقم يُكتب مُخفًى
  (`+971 50 *** 1234`)، والرمز وتعليمات الجلسة في الذاكرة فقط وتُمحى بانتهاء المكالمة.
- لا مفتاح ولا رمز ولا رقم كامل في السجلّ ولا في `/health`.

## توقيع Vercel → المرحّل (للنسخة التوأم في Vercel)

```
x-call-ts:  <الوقت بالملّي ثانية>
x-call-sig: hex( HMAC-SHA256( CALL_RELAY_SECRET, ts + '.' + METHOD + ' ' + PATH + '.' + rawBody ) )
```

`PATH` مسار الطلب بلا استعلام (`/call`، `/call/<id>`، `/call/<id>/cancel`)، و`rawBody` الجسم كما أُرسل حرفيًّا (فارغ لـ`GET`).
النسخة المرجعيّة: `signRelayHeaders` في `lib.mjs`.

## محليًّا

```bash
cd call-relay && npm ci && PORT=8080 node server.mjs     # ثمّ http://localhost:8080/health
node tests/call-relay.test.cjs                          # من جذر المستودع: بلا شبكة ولا ws (مقابس مزيّفة وساعة يدويّة)
```

الملفّات: `server.mjs` (الخادم والجسر، ws يُحمَّل عند أوّل مقبس)، `lib.mjs` (المنطق النقيّ: التواقيع، TwiML، الرقم، المخزن،
ترجمة الأحداث)، `Dockerfile`، و`package.json` + `package-lock.json` (اعتماد واحد: `ws` بإصدار مثبّت).
