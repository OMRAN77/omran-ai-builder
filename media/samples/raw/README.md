# ارفع فيديوهات النماذج هنا

ارفع الفيديو في هذا المجلّد باسم الوضع ورقم البطاقة، وسيُضغط تلقائيًّا بجودة عالية (١٠٨٠) ويظهر في بطاقته داخل صانع الفيديو بعد النشر.

| الوضع | البطاقة ٢ | البطاقة ٣ |
|---|---|---|
| كانفا فقط | `canvas-1.mp4` | `canvas-2.mp4` |
| فيديو AI فقط | `runway-1.mp4` | `runway-2.mp4` |
| فيديو اقتصادي | `minimax-1.mp4` | `minimax-2.mp4` |
| فيديو سينمائي | `omni-1.mp4` | `omni-2.mp4` |
| دمج الاثنين | `hybrid-1.mp4` | `hybrid-2.mp4` |
| Veo 3 | `veo-1.mp4` | `veo-2.mp4` |
| ممثل يتكلم | `actor-1.mp4` | `actor-2.mp4` |

- يقبل mp4 وmov وwebm. الحدّ في موقع GitHub ٢٥ ميغابايت للملفّ.
- **العنوان (اختياريّ):** ملفّ نصّيّ بنفس الاسم، مثل `omni-1.txt`، فيه سطر واحد يظهر تحت الفيديو ويُكتب في الوصف عند الضغط. بلا ملفّ يبقى المثال الحاليّ.
- بعد الرفع يعمل مسار «samples-ingest» في Actions دقيقة أو اثنتين، ثمّ ينشر Vercel.
