# معرفة عمران — مجلّد المعرفة الدائم

هذا المجلّد ملكُ **عمران الشامسي**. فيه كلّ ما يعرفه وكيله عن هذا المشروع.
أيّ وكيل ذكاء اصطناعيّ يعمل على هذا المستودع: **اقرأ هذه الملفّات أوّلًا.**

| الملفّ | ماذا فيه |
|---|---|
| `AGENTS.md` | الثوابت · الأبواب الخمسة المقفلة · القاعدة الأولى (لا فعل قبل السؤال) |
| `PROJECT.md` | بنية المستودع · النشر · العيوب |
| `STATE.md` | الحالة الحيّة · كلّ بند مفتوح |
| `DEPLOY.md` | خطّ النشر والتراجع المُثبت |
| `PITFALLS.md` | ١٧+ فخًّا مُثبتًا تجريبيًّا — تُقرأ قبل أيّ فحص |
| `DECISIONS.md` | قرارات عمران المسجّلة بتواريخها |
| `archive-intake-SKILL.md` | مهارة استقبال الأرشيف الكبير وفهرسته |

**القاعدة الأولى تعلو على كلّ ما تحتها: لا فعل قبل أمر مكتوب صريح من عمران.**
