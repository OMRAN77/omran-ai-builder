# إصلاح الذاكرة — ٧ أغسطس ٢٠٢٦

**الأمر:** «أصلح الذاكرة» (عمران، ٠٥:٤٨).

## العيب
`js/app-09-attach.js:1793` — مرشّح `__historyMsgs` كان:
```js
!m.providerLabel || m.isMergeHeader ||
(m.askAllReply && !m._failed && m.batchId && !cur.messages.some(...isMergeHeader...))
```
كل ردّ مساعد يحمل `providerLabel`. الشرط الثالث يتطلّب `askAllReply` — والدفعة العاديّة
في `app-09-attach.js:2580` تضع `askAllReply: false` (منذ v463) وبلا `batchId`.
⇒ **كل ردود المساعد كانت تسقط من السياق المُرسَل للمزوّد.** المُرسَل: أسئلة المستخدم فقط.
تعليق الكود نفسه كان يقول إنّ ردود المزوّد المختار «يجب أن تبقى في الذاكرة» — الشرط انكسر صامتًا.

## الإصلاح
```js
!m.providerLabel || m.isMergeHeader ||
(!m._failed && !m._loading &&
  !(m.batchId && cur.messages.some(x => x !== m && x.isMergeHeader && x.batchId === m.batchId)))
```
يبقى كل ردّ حقيقيّ · يسقط الفاشل والجاري وردود «اسأل الكل» التي يمثّلها رأس دمج.
مكسب جانبي: الفقاعة الفارغة الجارية (`_loading`) كانت تدخل الذاكرة سابقًا — الآن تسقط.
