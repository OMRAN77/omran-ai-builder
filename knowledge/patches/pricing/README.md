# رقعات الأسعار — مُجهَّزة ومُتحقَّقة · لم تُطبَّق
**٦ أغسطس ٢٠٢٦ · صفر سطر دُفع إلى `main` · الباب الماليّ ما زال مقفلًا**

هذه الشجرة **مسرح انتظار** لا إنتاج. كلّ ملفّ فيها نسخة كاملة جاهزة للدفع،
مبنيّة من إنتاج اليوم، ومتحقَّق منها بـ`diff` و`node --check`.
**لا يُدفع منها شيء إلّا بأمر ماليّ صريح مكتوب.**

## `usage/_usage.js` — البند ٢: وصل `plan` بالحصّة
**٢٧ سطرًا** — مُتحقَّق · `node --check` سليم.

- `PLAN_LIMITS = { plus: 60, basic: 60, pro: Infinity }`
- `limitFor(username)` — لا تُلقي استثناءً أبدًا؛ أيّ فشل ⇒ حدّ المجّاني.
- **الفحص المدفوع يقع بعد تجاوز حدّ المجّاني فقط** ⇒ المجّاني لا يدفع أيّ قراءة إضافيّة (المسار الحارّ بلا تكلفة).
- Pro (`Infinity`) اختُبر في موضعَي الاستدعاء: `count >= Infinity` ⇒ `false` · `remaining` ⇒ `Infinity` — مطابق تمامًا لسلوك حساب المالك.
- سبع حالات `plan` اختُبرت (`undefined` `''` `free` `plus` `PRO` `garbage` `null`) — كلّها صحيحة، والمجهول يسقط إلى ٢٠.
- `GUEST_LIMIT` والضيوف والمالك: **بلا تغيير.**
