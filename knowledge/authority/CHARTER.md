## التفويض الممنوح (٥ أغسطس ٢٠٢٦، ١١:١٤ دبي)

نصّ المانح: **«أعطيك صلاحية الموقع كاملة»** — بعد أن سبقه: «ابدأ بالحذف الكامل» و«كمّل الإجراء».

**ما صار مأذونًا به بلا سؤالٍ مسبق:**
- الكتابة على `main` مباشرةً في مستودع `OMRAN77/omran-ai-builder`.
- تعديل ملفات الواجهة والمنطق والتصميم ونشرها.
- إنشاء الفروع وطلبات الدمج والتعليقات والمسائل.

**شروط ثابتة على كل تنفيذ:**
1. **نسخة تراجع محفوظة قبل كل دفعة** + سكربت رجوع جاهز.
2. **تحقّق بعد الدفع** من المحتوى الفعلي على `main` (لا الاكتفاء بنجاح الاستدعاء).
3. **تقرير صريح** بالالتزام والهاش وعدد الأسطر.
4. **حصّة يومية:** ≤ ٤٠٠ سطر مُعدَّل / يوم. هجرة تدريجية (Strangler) لا إعادة كتابة شاملة.

## الخطوط الحمراء — قائمة بحكم الأمانة، لا تُفتح إلا بأمرٍ مكتوبٍ منفصل لكل حالة

| المحظور | السبب |
|---|---|
| `stripe` / `paypal` / منطق النقاط والرصيد والشحن | مال حقيقي — خطأٌ واحد = خسارة |
| بيانات المستخدمين | خصوصية |
| حذف مستودع أو مشروع أو قاعدة بيانات | لا رجعة فيه |
| صرف أيّ مال | قرار المالك وحده |
| نشر مفاتيح أو أسرار | أمن |

> ملاحظة: حذف اللوحة اليمنى (٥ أغسطس) لمس **عرض** الرصيد وزرّ اختصارٍ للإعدادات فقط — بإذن صريح وبعد تحذير. **منطق الدفع لم يُمَسّ.**
