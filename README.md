# عالم المكعبات

لعبة مكعبات أصليّة تُلعب في المتصفّح، على الحاسوب والجوّال، بثلاثة عوالم: **كوكب** (كوكب غريب)، **واحة** (صحراء وحصن)، **ظلام** (غابة وأطلال).
عربيّة، بلا تسجيل دخول، وبلا خطوة بناء: الملفّات تُنشر كما هي.

## ما فيها
- مشي وركض وقفز وسباحة وطيران، حفر وبناء، ٩ مربّعات وحقيبة بـ٢٧ خانة و٤ خانات لبس ويد ثانية.
- صحّة وجوع وحاجة كلّ عالم (أكسجين، ماء، دفء)، حيوانات تُصاد ووحوش تهاجم، ليل ونهار ومطر باختيارك (Q).
- تصنيع بوصفات، صندوق وباب وطاولة ومشعل وسرير، سيوف وفؤوس ومعاول ودروع.
- كهف جديد كلّ يوم فيه ذهب وألماس، كنز يوميّ بخريطة، مهامّ ظاهرة وسرّيّة، ملابس وتصميم شخصيّتك، تاجر.
- أجهزة: كاشف كنوز، كاميرا، خريطة حيّة، شنطة إضافيّة، جهاز التاجر، بلّورة المكان.
- ثعلب يدلّ على الكنز، تنين صغير يحمل أغراضك، سلحفاة الرمال، غزال الظلال.
- رسالة كلّ يوم، غريب بمهمّة، جزيرة في السماء، بوّابة ومتاهة متحرّكة.
- لعب جماعيّ حتّى ٤ بكود من أربعة أرقام: صاحب الغرفة يُدخل ويرفض ويطرد ويرفع مشرفًا، مايك، هدايا، مسابقة بناء، مهمّة فريق.
- قائمة Esc: إنجازات، إحصائيّات، ملاحظة وبلاغ خطأ، إعدادات (صوت، سرعة النظر، الصورة، الصعوبة، أزرار التحكّم)، حفظ.
- الحفظ في المتصفّح نفسه، حفظ لكلّ عالم.

## المجلّدات
| المسار | ما فيه |
|---|---|
| `index.html` | صفحة اختيار العالم |
| `styles/<عالم>/` | كلّ عالم: توليده، مشاهده، واجهته |
| `shared/` | ما تشترك فيه العوالم: التحكّم، الحقيبة، التصنيع، المخلوقات، الجماعيّ، الحفظ… |
| `vendor/` | three.js r187 والخطوط (منقولة كما هي، انظر `vendor/NOTICE.txt`) |
| `api/play-room.js` | وسيط تعارف الغرف (اللاعبون يتّصلون مباشرة بعده) |
| `api/feedback.js` | ملاحظات اللاعبين وبلاغاتهم |
| `tests/` | `npm test` |
| `tools/` | فحوص المتصفّح (لا تُنشر) |
| `knowledge/` | سجلّ القرارات والفخاخ |

## التشغيل محلّيًّا
أيّ خادم ملفّات ثابتة من جذر المشروع:
```bash
python3 -m http.server 8080
```
ثمّ `http://localhost:8080/`. اللعب الفرديّ يعمل كاملًا هكذا؛ الغرف والملاحظات تحتاج الدالّتين (على Vercel).

## الاختبارات
```bash
npm test
```
وفحوص اللعب في متصفّح حقيقيّ (تحتاج Playwright وChromium):
```bash
npm run play:desktop
```
```bash
npm run play:touch
```
```bash
npm run play:together
```

## النشر (Vercel)
1. اربط المستودع بمشروع Vercel جديد (بلا إعدادات بناء: Framework = Other).
2. للغرف والملاحظات أضف متغيّرَي التخزين (Upstash Redis): `UPSTASH_REDIS_REST_URL` و`UPSTASH_REDIS_REST_TOKEN`.
3. لقراءة الملاحظات أضف `BLOCKWORLD_ADMIN_KEY` بقيمة تختارها، ثمّ افتح `/api/feedback?key=<القيمة>`.

بلا المتغيّرات اللعبة تعمل؛ «العب مع ربعك» و«أرسل ملاحظة» يقولان إنّهما متوقّفان.

## ملاحظات صادقة
- الصفحة لا تُفهرس في محرّكات البحث (رابط شخصيّ).
- اللعب الجماعيّ اتّصال مباشر بين المتصفّحات: كلّ لاعب يرى عنوان شبكة الآخر، وبعض شبكات الجوّال تمنع الاتّصال المباشر (لا خادم ترحيل).
- الحفظ في المتصفّح لا في حساب: جهاز آخر = عالم جديد.
